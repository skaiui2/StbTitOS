# LTTit

LTTit 是一个分布式运行时执行框架,让许多独立节点像一台机器一样工作。

它为多节点系统提供统一的执行抽象，使整个集群能够以单一系统镜像的方式运行。

LTTit 不是一个 RTOS，而是一个分布式运行时系统。RTOS 解决单节点的问题，而 LTTit 解决整个系统的问题。

LTTit 是一个更高层的分布式执行环境，提供：

统一命名空间：所有节点的资源都在同一棵全局树中

统一访问语义：访问远程资源与访问本地资源完全一致

统一执行模型：程序可以在任意节点上加载、执行、迁移、恢复

统一通信框架：节点之间通过路由、RPC、可靠传输协作

LTTit 的目标不是管理硬件，而是统一整个系统的执行逻辑。

# 统一视图的命名空间

在LTTit，tree命令就是打印一颗prefix树的节点，这颗树就是统一视图的命名空间。

```
> tree
└── root
    ├── nodeA
    │   └── mem
    │       └── region1
    └── nodeB
        └── dev
            ├── led
            └── led1
```

# 快速开始

LTTit 没有平台要求，所以既可以运行在单片机上，也可以运行在Linux用户态，但是单片机集群是很好的实验场所。

所以，我在多单片机上开发LTTit，当然，你只需要两块单片机就能运行LTTit 的demo。
