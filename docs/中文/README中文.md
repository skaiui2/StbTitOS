# lttit

lttit 是一个实验性框架，我设计它的目的是把一百块单片机当成一块来用。

我将其称之为“鸟群操作系统”（Tit Cluster Operating System），这种操作系统具备两个核心特性：

1.让多个节点协作形成一个整体

2.支持在运行时动态修改节点的程序逻辑

## 系统组件

lttit 由多个可独立移植的模块组成，基础模块包括：

- **RTOS 内核**：双调度器（RT/BE）、同步原语、定时器
- **文件系统（FS）**：轻量类 Unix FS
- **内存管理（mg）**：多种适配 MCU 的分配器
- **数据结构库（lib）**：红黑树、Radix 树、哈希表、链表等
- **网络协议栈（TCP/IP）**：简化版 TCP/IP
- **Shell 与文本编辑器**：交互式命令行与轻量编辑器

这些组件构成了 lttit 的基础运行环境，此外，核心模块为CSC和CCBPF。

### 核心能力

#### CSC：分布式协议栈
让多个 MCU 节点像“一台机器”一样协同工作，提供：
- 路由（CCNET）
- 可靠传输（SCP）
- 远程调用（CCRPC）

#### ccBPF：动态编程组件
一个 C 子集编译器 + BPF 虚拟机，用于在运行时动态修改节点逻辑，例如调度策略、防火墙规则、流控算法等。

CSC 负责“让节点组成整体”，ccBPF 负责“让整体改变自身”。

### 语义层world

这是一切皆文件的最直接的体现，让所有节点，所有行为，都抽象为一个文件系统。

我希望数学与形式化语义能够成为LTTit的基础，LTTit的数学与形式化主要侧重以下部分：

1. 传输拥塞控制算法的数学分析，如何设计分布式传输协议？
2. 调度算法的数学分析，如何设计分布式调度算法？
3. 分布式算法的形式化分析，如何解决分布式容错、一致性等问题？

我希望使用非线性动力学、随机过程、凸优化、排队论、分布式算法等数学知识分析并设计相关模块。
